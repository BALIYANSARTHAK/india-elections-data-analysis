# 🇮🇳 70+ Years of Elections in India: A Data-Driven Analysis (1951–2019)

## 📌 Project Overview
A comprehensive analysis of all 17 Lok Sabha general elections from 1951 to 2019,
covering party performance, voter turnout, FPTP distortion, and regional politics.

## 🛠️ Tools Used
Python · Pandas · NumPy · Matplotlib · Seaborn · Scikit-learn

## 📊 Key Findings
- BJP grew from 2 seats (1984) to 303 seats (2019) — fastest rise in Indian democracy
- INC collapsed 90% from 404 seats (1984) to 44 seats (2014)
- FPTP system gave BJP a +18.4 pp seat bonus in 2019 (37.4% votes → 55.8% seats)
- Voter turnout rose from 45.7% (1951) to 67.4% (2019) despite 5× larger electorate
- K-Means clustering identified 4 distinct state political profiles
